# Original Christmas audio

Eight real MP3s (four choices × two durations) are stored as imported asset
pointers in src/assets, rather than repository binaries. No Music has no file.
The requested five choices therefore need eight files, not ten.

Audio is an original synthesized bell melody with soft chord accompaniment.
It is not a recording, cover, or reproduction of the named Christmas songs.
Choice names are retained as menu labels, with an explicit original-instrumental
disclosure. No third-party recordings, samples, or claimed music licenses were used.

Reserved file names:
- pasko-sa-nayon-5sec.mp3 / pasko-sa-nayon-10sec.mp3
- christmas-in-our-hearts-5sec.mp3 / christmas-in-our-hearts-10sec.mp3
- ang-pasko-ay-sumapit-5sec.mp3 / ang-pasko-ay-sumapit-10sec.mp3
- jingle-bells-pinoy-5sec.mp3 / jingle-bells-pinoy-10sec.mp3

The app uses musicAssetUrl() and decodes each real asset before enabling generation.
If replacing them with recordings, confirm commercial synchronization and distribution
rights first and update the attribution/disclosure. Preserve 5/10-second versions.
